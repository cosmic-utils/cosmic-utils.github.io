COSMIC Utils projects are all open source and welcome the spirit of open collaboration.
Head over to the source code of any of the [projects](/) above and help however you feel
necessary!

To list a new application, applet, theme, service or script here, open a pull request
against [cosmic-project-collection](https://github.com/cosmic-utils/cosmic-project-collection) —
this site's project list is generated from that repository's data on every build.
