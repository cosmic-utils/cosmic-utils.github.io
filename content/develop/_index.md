Build a standalone window with the **App Template**, or a tool that lives in the Panel or Dock with the **Applet Template**. Both use Rust and libcosmic.

Start with setup, then pick the chapter for the kind of project you’re building. The [icon design chapter](@/develop/icon.md) covers launcher artwork for standalone apps. The publishing chapter covers where to distribute your project and how to add it to the COSMIC Orbit catalog.

For help with widgets, application state, and messages, see the [libcosmic book](https://pop-os.github.io/libcosmic-book/) and [API reference](https://pop-os.github.io/libcosmic/cosmic/).
